# লাইভ ক্যামেরা সেটআপ — কোনো ভিপিএস ছাড়া (Imou / EZVIZ)

> এই গাইডটা সেই পথ, যেখানে **ভিপিএস নেই, খামারে ল্যাপটপ/ডেস্কটপ রাখতে হয় না, রাউটারে পোর্ট খুলতে হয় না।**

## কেন এটা কাজ করে

Imou Life বা EZVIZ অ্যাপে ক্যামেরা যোগ করলে ক্যামেরাটা নিজেই বাইরের দিকে (outbound) ক্লাউডে সংযোগ
রাখে। তাই অ্যাপে যেখান থেকেই হোক লাইভ দেখা যায় — এমনকি CGNAT/পাবলিক IP না থাকলেও। আমরা ঠিক ওই
সংযোগটাই ব্যবহার করি:

```
সেলারের ফোন (Imou Life / EZVIZ অ্যাপ)
        │  ক্যামেরা নিজেই ক্লাউডে যুক্ত
        ▼
   প্রস্তুতকারকের ক্লাউড  ◄──── Vercel সার্ভার (AppSecret দিয়ে সাইন করা কল)
                                      │  প্রিমিয়াম/ট্রায়াল চেক
                                      ▼
                            গ্রাহকের ব্রাউজার (আমাদের নিজের ডোমেইন)
```

ক্যামেরার RTSP ঠিকানা, সিরিয়াল ও API কী — কোনোটাই ব্রাউজারে যায় না। প্রতিটি সেগমেন্ট আমাদের
`/api/cam/live/...` দিয়ে যায়, তাই প্রিমিয়াম বন্ধ হলে ছবিও বন্ধ।

## ১. সেলারকে ক্যামেরা কিনতে বলুন (যে ক্যামেরা কিনবেন, সেটাই আসল সিদ্ধান্ত)

| ক্যামেরা | ফোনের অ্যাপ | আমাদের কোডে সাপোর্ট | দাম (বাংলাদেশ) |
| --- | --- | --- | --- |
| **Imou** (Ranger / Cue / Bullet) | Imou Life | ✅ `imou` | ২,৫০০–৫,০০০ |
| **EZVIZ** (Hikvision-এর ব্র্যান্ড) | EZVIZ | ✅ `ezviz` | ৩,০০০–৬,০০০ |
| TP-Link Tapo / Xiaomi | Tapo / Mi Home | ❌ (ক্লাউড API নেই) | — |
| Dahua / Hikvision DVR | DMSS / iDMSS | ⚠️ শুধু ভিপিএস পথে | — |

> ⚠️ **Tapo/Xiaomi কেন নয়:** ওদের ক্লাউডে থার্ড-পার্টি API নেই, আর RTSP শুধু ঘরের নেটওয়ার্কে কাজ করে।
> তাই ওই ক্যামেরা দিয়ে এই পথে লাইভ দেখানো যাবে না — ভিপিএস লাগবে।
> আপনার কাছে এখন যে **Dahua DH-XVR1B16-I-SSI** আছে, সেটা DMSS দিয়ে চলবে, কিন্তু ভিপিএস ছাড়া
> ওয়েবসাইটে আনা যাবে না (Dahua-র ক্লাউড API বাণিজ্যিক চুক্তি ছাড়া খোলা হয় না)।

## ২. একবারের কাজ: ডেভেলপার অ্যাকাউন্ট (ফ্রি)

### Imou হলে
1. <https://open.imoulife.com> → Register → **একই লগইন** দিয়ে যা Imou Life অ্যাপে আছে।
2. Console → **My App** → App Information → Edit → সেভ → **AppId** ও **AppSecret** কপি।
3. ডেটা সেন্টার: বাংলাদেশের অ্যাকাউন্ট **Singapore** (`openapi-sg.easy4ip.com`)।

### EZVIZ হলে
1. <https://open.ys7.com> → Register।
2. My App → **appKey** ও **appSecret** কপি।

> AppSecret কখনো Git-এ, চ্যাটে বা স্ক্রিনশটে দেবেন না — শুধু Vercel-এর Environment Variables-এ।

## ৩. Vercel → Settings → Environment Variables

| নাম | মান | কখন দরকার |
| --- | --- | --- |
| `IMOU_APP_ID` | Imou AppId | Imou ক্যামেরা |
| `IMOU_APP_SECRET` | Imou AppSecret | Imou ক্যামেরা |
| `IMOU_API_HOST` | `https://openapi-sg.easy4ip.com` | ঐচ্ছিক |
| `EZVIZ_APP_KEY` | EZVIZ appKey | EZVIZ ক্যামেরা |
| `EZVIZ_APP_SECRET` | EZVIZ appSecret | EZVIZ ক্যামেরা |
| `STREAM_TOKEN_SECRET` | ৩২+ অক্ষরের র‍্যান্ডম স্ট্রিং | **জরুরি** — টোকেন ও সেগমেন্ট সিগনেচার এটাতেই |

`STREAM_TOKEN_SECRET` তৈরি করুন:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

তারপর **Redeploy** করুন।

## ৫. সেলারের ক্যামেরা সাইটে যোগ করা

প্রতিটি সেলারের জন্য একবার — **অ্যাডমিন প্যানেল → ক্যামেরা → নতুন**:

| ফিল্ড | কী দিতে হবে |
| --- | --- |
| খামার | সেলারের খামার |
| ক্যামেরার নাম | যেমন `মুরগিঘর — ক্যামেরা ১` |
| **স্ট্রিম সোর্স** | `Imou Life অ্যাপ` বা `EZVIZ অ্যাপ` |
| **ডিভাইস সিরিয়াল** | Imou: অ্যাপ → ডিভাইস → Device ID<br>EZVIZ: ৯ অক্ষরের সিরিয়াল (যেমন `F00497273`) |
| **চ্যানেল নম্বর** | একক ক্যামেরা হলে `0` |
| স্টেটাস | `অনলাইন` |
| সক্রিয় | ✓ |
| প্রিমিয়াম | ✓ (গ্রাহককে প্রিমিয়াম লাগবে) |

সেভ করার পর `/live/farms` → ওই খামার → ক্যামেরা — প্রিমিয়াম/ট্রায়াল থাকলে ছবি চালু হবে।

> সেলার নিজে `/seller/cameras` থেকে **ক্যামেরা রিকোয়েস্ট** দিতে পারেন। আপনি ইনস্টল করে উপরের
> তথ্যগুলো অ্যাডমিন প্যানেল থেকে বসিয়ে দেবেন। সেলারের কাছে Device ID পাঠানোর দরকার নেই।

## ৬. যাচাই

- অ্যাডমিন → ক্যামেরা: উপরে কোনো হলুদ/নীল সতর্কবার্তা নেই = কী ঠিক আছে।
- `/live/farms/<খামার>` → "লাইভ লোড হচ্ছে…" → কয়েক সেকেন্ডে ছবি।
- ব্রাউজারের Network ট্যাবে দেখবেন: `index.m3u8` → তারপর `seg/...` সবই `200`।

## ৭. সীমাবদ্ধতা — যা জানা থাকা ভালো

| বিষয় | বাস্তবতা |
| --- | --- |
| দেরি (latency) | HLS, তাই ~৫–১০ সেকেন্ড। খামার দেখানোর জন্য ঠিক, চোর ধরা/দরজা খোলার জন্য নয়। |
| ব্যান্ডউইথ | প্রতি দর্শক ঘণ্টায় ~৫০–৭০ MB (SD স্ট্রিম)। Vercel Hobby-র ১০০ GB = ~১,৫০০ দর্শক-ঘণ্টা/মাস। |
| একসাথে দর্শক | Imou/EZVIZ ক্লাউডের নিজের সীমা আছে (সাধারণত ২–৫ জন একসাথে প্রতি ক্যামেরায়)। |
| ডিভাইস লিমিট | আমাদের `premium_devices` আলাদাভাবে কাজ করে। |
| অডিও | এখন শুধু ছবি, শব্দ নেই। |

| `403 অনুমোদিত নয় এমন স্ট্রিম সার্ভার` | প্লেলিস্টের লিংক পুরোনো — পেজ রিফ্রেশ করুন |

## ৯. বিকল্প: ভিপিএস পথ (RTSP)

Imou/EZVIZ ব্যবহার না করলে পুরোনো পথ আছে — `docker-compose.stream-vps.yml` ও
`STREAM_PROXY_TARGET`, বিস্তারিত `README.md` §১০-এ। বিক্রেতার ক্যামেরা ডিভাইসে `cloud_provider`
`none` রাখলে ওই পথেই চলবে।
