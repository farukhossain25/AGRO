# লাইভ টিভি — m3u/m3u8 দিয়ে লাইভ চালানো (পাবলিক IP ছাড়া)

**সংক্ষেপে:** খামারের লাইভ সেকশনে এখন দুটো ধরনের জিনিস চলে — আসল CCTV ক্যামেরা (যেমন আগে) আর **লাইভ টিভি চ্যানেল** (`.m3u8` / `.m3u` লিংক)। TV চ্যানেলের জন্য কোনো পাবলিক IP, ভিপিএস, রাউটার পোর্ট বা ইনস্টলেশন লাগে না। পাবলিক IP পেলে ক্যামেরা সব একই জায়গা থেকে সেট করবেন; TV-র লাইনগুলো তখন শুধু মুছে দিলেই হবে।

---

## ১. কে কোথায় যোগ করবে

| কোথায় | কী দিয়ে |
|---|---|
| **অ্যাডমিন প্যানেল** → ক্যামেরা (`/foisal/cameras`) | স্ট্রিম সোর্স = **“লাইভ টিভি চ্যানেল (m3u8)”**, তারপর লিংক ঘরে চ্যানেলের ঠিকানা |
| **সেলার ড্যাশবোর্ড** → `/seller/cameras` | “লাইভ টিভি চ্যানেল যোগ করুন” ফর্ম — নিজের খামারে নিজে যোগ/মুছতে পারবেন |

সেলার শুধু **নিজের** খামারে, শুধু **`tv`** ধরনের, শুধু **https** লিংক দিতে পারবে। ক্যামেরা বসানো/বদলানো আগের মতোই অ্যাডমিনের হাতে।

## ২. কোন লিংক চলবে

| লিংক | কী হয় |
|---|---|
| `https://…/channel.m3u8` | সরাসরি চলবে (HLS) |
| `https://…/list.m3u` | তালিকার **প্রথম HLS চ্যানেলটি** চলবে |
| `https://…/…abc4.m3u8` (যেটা আসলে **চ্যানেল তালিকা**) | ✅ সার্ভার ভেতরটা পড়ে নিজেই তালিকার চ্যানেলটি বেছে নেয় (iptvcat-এর লিংক এভাবেই চলে) |
| `http://…` | ❌ প্রত্যাখ্যাত — https বাধ্যতামূলক |
| `https://127.0.0.1/…`, `https://10.x/…`, `https://169.254.169.254/…` | ❌ প্রত্যাখ্যাত (ভেতরের নেটওয়ার্ক) |
| পোর্ট ৪৪৩ ছাড়া অন্য পোর্ট | ❌ প্রত্যাখ্যাত |

একাধিক চ্যানেল চাইলে **প্রতিটি চ্যানেলের জন্য আলাদা রো** বানান — একটি রো = একটি চ্যানেল।

### লিংক সেভ করার আগে পরীক্ষা করুন

`/foisal/cameras` পেজে চ্যানেল ফর্মের উপরে **“লিংক পরীক্ষা করুন”** কার্ড আছে। লিংকটা ওখানে দিলে সার্ভার
প্লেয়ারের মতোই পুরো চেইন হেঁটে দেখায় — কোন ধাপে কী পাওয়া গেল (চ্যানেল তালিকা / মাস্টার / স্ট্রিম),
কোথায় গেল, আর কোথায় আটকাল। তাই “লোড হচ্ছে…” দেখে আন্দাজ না করে সেভের আগেই জানা যায় লিংকটা মরা কি না।

> ⚠️ ফাইলের নাম `.m3u8` হলেই সেটা স্ট্রিম নয়। iptvcat/m3u4u-র মতো সার্ভিস **চ্যানেল তালিকা**ও
> `.m3u8` নামে দেয়। এখন সার্ভার **এক্সটেনশন নয়, ভেতরের লেখা** দেখে সিদ্ধান্ত নেয় — তাই এমন লিংকও চলে।

### কোন পেজে চ্যানেল দেখা যাবে

| জায়গা | কী দেখায় |
|---|---|
| খামারের নিজের পেজ (`/live/farms/<slug>`) | সব ক্যামেরা + সব চ্যানেল, চ্যানেল **আগে** — লগইন ছাড়াই চলে |
| লাইভ খামার (`/live`) | খামার কার্ডে “১ লাইভ · ১ টিভি” — চ্যানেল থাকলে খামারটা লাইভ হিসেবে উপরে ওঠে |
| খামার ডিরেক্টরি (`/live/farms`) | “১টি ক্যামেরা অনলাইন · ১টি টিভি চ্যানেল চলছে” |
| হোমপেজের লাইভ স্ট্রিপ | “১টি টিভি চ্যানেল এখন লাইভ” |
| **পণ্যের পেজ** (`/products/...`) | সাপ্লায়ারের নিচে সেই খামারের চ্যানেল, “লাইভ টিভি” শিরোনামে |

> ⚠️ **একটা শর্ত:** চ্যানেলটি একটি **খামারের** সাথে যুক্ত হতে হবে (`খামার` ঘরটি ফাঁকা রাখা যাবে না)। ফর্মে
> এটা বাধ্যতামূলক। কারণ খামার-পেজ, পণ্যের পেজ ও ডিরেক্টরি — সবই খামার ধরে চ্যানেল খোঁজে। খামার ছাড়া
> চ্যানেল শুধু অ্যাডমিন তালিকায় থাকবে, কোনো ভিজিটর সেটা দেখবে না।

## ৩. দেখতে কে পারবে

**সবাই — লগইন ছাড়াও।** টিভি চ্যানেল প্রিমিয়াম সাবস্ক্রিপশন, ট্রায়াল বা ভিউয়ার-ক্যাপের আওতায় **নয়**। (`is_premium` টিক থাকলেও `tv` সবসময় ফ্রি — এটা কোডে নির্ধারিত, ফর্মে নয়।)

তবু নিরাপত্তা অটুট:
- প্রতি চ্যানেলের টোকেন **স্বাক্ষরিত**, ৫ মিনিটে মেয়াদোত্তীর্ণ, এবং **শুধু ওই একটি চ্যানেলের** জন্য বৈধ
- প্লেলিস্ট সার্ভার-সাইডে রিরাইট হয় — প্রতিটি সেগমেন্টের নিজস্ব সিগনেচার থাকে
- ব্রাউজার কখনো মূল স্ট্রিম হোস্টের ঠিকানা পায় না

## ৪. ডেটাবেস (একবার চালাতে হবে)

```

```

> **এখনো চালানো হয়নি।** আপনার অনুমোদন ছাড়া কোনো মাইগ্রেশন চালাব না।

## ৫. CCTV-তে ফেরা

কিছুই ভাঙা হয়নি — Imou / EZVIZ / MediaMTX (RTSP) / ক্লাউড HLS সব আগের মতোই আছে। পাবলিক IP বা ডিভাইস প্রস্তুত হলে শুধু নতুন ক্যামেরা রো বানাবেন, অথবা `tv` রো-টির স্ট্রিম সোর্স বদলে দেবেন।

## ৬. যাচাই করা হয়েছে

| পরীক্ষা | ফল |
|---|---|
| খামার পেজে `tv` চ্যানেল দেখা যায় | ✅ “টেস্ট টিভি”, “লাইভ টিভি”, “টিভি চ্যানেল” রেন্ডার হচ্ছে |
| `/live`-এ চ্যানেল কাউন্ট আলাদা | ✅ “টিভি চ্যানেল ১”, ক্যামেরা কাউন্ট অপরিবর্তিত |
| লগইন ছাড়া টোকেন | ✅ `mode: public`, সাবস্ক্রিপশন ছাড়াই |
| নকল/বদলানো টোকেন | ✅ 401 |
| SSRF — `169.254.169.254`, `localhost`, `10.0.0.7` | ✅ তিনটিই 403/502, বাংলা বার্তা |
| লগইন ছাড়া সেলার API | ✅ 401 |
| পুরো স্যুট | ✅ 178 checks · 36/36 resilience · 186 routes |

### রাউন্ড ৭.১ — “লোড হচ্ছে” চিরকাল আটকে থাকার বাগ

আসল লিংক `https://list.iptvcat.net/my_list/s/4e79….m3u8` ছিল **একটি চ্যানেলের তালিকা** (Deshi TV →
deshitv.deshitv24.net), স্ট্রিম নয়। আগের কোড `.m3u8` এক্সটেনশন দেখেই সেটা hls.js-কে দিয়ে দিত ⇒
প্লেয়ার চিরকাল “লাইভ লোড হচ্ছে…” দেখাত, ভুলও দেখাত না।

| পরীক্ষা | ফল |
|---|---|
| ওই লিংক → আসল স্ট্রিম | ✅ দুই হপ পেরিয়ে `…/live/myStream/playlist.m3u8?checkedby:iptvcat.net` |
| তালিকা → তালিকা → স্ট্রিম | ✅ |
| নিজেকে নির্দেশ করা তালিকা (লুপ) | ✅ থেমে যায়, বাংলা ত্রুটি — ঝুলে থাকে না |
| ২০০ + HTML (লগইন পেজ / “offline” নোটিশ) | ✅ স্ট্রিম হিসেবে পাস হয় না, কারণ দেখায় |
| ৪০৪ / মৃত চ্যানেল | ✅ “চ্যানেল তালিকা পড়া যায়নি (404)” |
| ক্লাসিফায়ার ইউনিট | ✅ ১০/১০ |
| চেইন রিপ্লে (তালিকা, ডিপ লিস্ট, লুপ, HTML, ৪০৪) | ✅ ৬/৬ |
| টেস্টার রুটের হপ-রিপোর্ট | ✅ ৫/৫ (ভালো / তালিকা-মধ্যে-তালিকা / HTML / মৃত / ৪০৪) |

### রাউন্ড ৮ — “লাইভ খামারে দেখাচ্ছে না”

দুইটা আলাদা বাগ ছিল, একই উপসর্গে:

| বাগ | কারণ | ফিক্স |
|---|---|---|
| পণ্যের পেজে “এই ক্যামেরার স্ট্রিম কনফিগার করা হয়নি” | পেজ সব রো-কেই RTSP প্লেয়ারে পাঠাত, Imou/EZVIZ/টিভি রো-তে `stream_key` থাকে না | `cloud_provider` দেখে প্লেয়ার বাছা হয় (`lib/supplier.ts`) |
| m3u8 চ্যানেল লাইভ-খামার হিসেব হত না | “লাইভ” মানে শুধু `online_cameras` কাউন্ট, টিভি চ্যানেল বাদ | `lib/live-counts.ts` — ক্যামেরা ও চ্যানেল দুটোই লাইভ |

| পরীক্ষা | ফল |
|---|---|
| `cameraSourceOf` (tv/hls/imou/ezviz/none/null) | ✅ ৮/৮ |
| লাইভ-গণনা (শুধু ক্যামেরা / শুধু চ্যানেল / দুটোই / কিছুই না / null) | ✅ ৫/৫ |
| পণ্যের পেজ, টিভি রো | ✅ “লাইভ টিভি”, “সবার জন্য ফ্রি”, কোনো ত্রুটি কার্ড নেই |
| টিভি রো → `/api/stream/token` | ✅ 409 + “ক্লাউড প্লেয়ার দিয়ে চলবে” |
| টিভি রো → `/api/cam/token` | ✅ 200, `mode: public`, লগইন ছাড়া |
| খামার পেজের কাউন্ট | ✅ “১টি ক্যামেরা ও ১টি টিভি চ্যানেল” |
| `/live` ও ডিরেক্টরি ব্যাজ | ✅ “১ লাইভ · ১ টিভি”, “১টি টিভি চ্যানেল চলছে” |

**যা এখানে টেস্ট করা যায়নি:** বাইরের কোনো আসল IPTV হোস্টে আউটবাউন্ড TLS বন্ধ থাকায় সত্যিকারের চ্যানেল স্ট্রিম চালানো যাচাই হয়নি। `.m3u` পার্সিং ও গার্ড আলাদাভাবে টেস্ট করা হয়েছে।
