# CCTV লাইভ — এখান থেকে শুরু করুন (এক পেজের চেকলিস্ট)

**এই ডকে যা আছে:** Imou ক্যামেরা কিনে আপনার ওয়েবঅ্যাপে লাইভ দেখাতে ঠিক কী কী করতে হবে —
ক্রম অনুযায়ী, কোনটা আগে, কোনটা পরে। আর কোথায় কোড বদলাতে হবে (প্রায় কোথাও না)।

**রেকর্ডিং কোথাও নেই** — `mediamtx.yml`-এ `record: false`। শুধু লাইভ।

## ০. এক নজরে: কোড বদলাতে হবে কি?

| Imou ক্লাউড পথে ওয়েবঅ্যাপে দেখানো | ❌ না | কোড আগেই লেখা (`lib/camera-cloud.ts`, `/api/cam/*`, `CloudPlayer`) |
| VPS পথে (RTSP → MediaMTX) দেখানো | ❌ না | কোড আগেই লেখা (`/api/stream/*`, `Caddyfile`) |

> এমন কিছু বের হয় যা এখনো সাপোর্ট করে না — তখন আগে আপনাকে বলব, অনুমতি নিয়ে করব।

## ১. 🔴 ধাপ ০ — ১০ মিনিটের ফ্রি টেস্ট (ক্যামেরা কেনার আগেই)

**লক্ষ্য:** ফার্মের ক্যামেরা ইন্টারনেট থেকে সরাসরি দেখা যায় কি না — সেটা জানা।
**যা লাগবে:** ফোন (WiFi + মোবাইল ডাটা), VLC অ্যাপ, Dahua XVR-এর পাসওয়ার্ড, XVR-এর IP।
**খরচ:** ৳০।

### ১.১ নেটওয়ার্কের তথ্য বের করুন (ফোনেই)

XVR-তে স্ক্রিন নেই, তাই DMSS অ্যাপ বা রাউটার থেকেই তথ্য নিতে হবে:

**ক) XVR-এর IP**
- রাউটারের অ্যাডমিন প্যানেল (ব্রাউজারে `192.168.0.1` বা `192.168.1.1`) → DHCP Client List
- সেখানে `Dahua` বা MAC অ্যাড্রেস দেখে IP নিন — যেমন `192.168.0.108`
- বা DMSS → ডিভাইস → সেটিংস → ডিভাইস ইনফো → IP

**খ) XVR-এর পাসওয়ার্ড**
এই ৩টার একটা হবে (পুরোনো Dahua-র সাধারণ ডিফল্ট):
```
admin / admin
admin / 123456
admin / নিজের সেট করা পাসওয়ার্ড
```
> পুরোনো Dahua ওয়েব ইন্টারফেসে `admin/admin` চলে। না হলে DMSS-এ যেই পাসওয়ার্ড দিয়ে লগইন করেন, সেটাই।

**গ) DHCP-তে IP বেঁধে দিন**
রাউটারের DHCP সেটিংসে XVR-এর MAC-কে fixed/reserved IP দিন। নাহলে রিবুটে IP বদলে গেলে কনফিগ ভাঙবে।

### ১.২ VLC ইনস্টল করুন

- Play Store → **VLC for Android** (VideoLAN) → ইনস্টল
- ইন্টারনেট ছাড়া চলে, বিজ্ঞাপন নেই

### ১.৩ প্রথম টেস্ট — ঘরের WiFi দিয়ে (ভেতরের নেটওয়ার্ক)

**এটা এখনো কোনো প্রমাণ না**, শুধু নিশ্চিত হওয়া যে লিংক আর পাসওয়ার্ড ঠিক আছে।

1. **WiFi চালু** রাখুন
2. VLC → বাম মেনু → **Stream** → `New stream`
3. এই লিংক দিন (IP আর পাসওয়ার্ড বদলে):
   ```
   rtsp://admin:admin@192.168.0.108:554/cam/realmonitor?channel=1&subtype=1
   ```
4. **ছবি এলে** → লিংক ঠিক ✅ → এখন আসল টেস্টে যান
5. **না এলে** → পাসওয়ার্ড/IP ভুল, অথবা RTSP বন্ধ। **এখানেই থামুন**, ঠিক করে আবার

> `channel=1` = Dahua-তে ১ নম্বর চ্যানেল · `subtype=1` = সাব-স্ট্রিম (হালকা)
> ছবি এলে `subtype=0` দিয়ে HD-ও টেস্ট করতে পারেন — পরে মোবাইল ডাটায় ভারী লাগবে

### ১.৪ আসল টেস্ট — মোবাইল ডাটা দিয়ে (এটাই নির্ণায়ক)

**⚠️ WiFi সম্পূর্ণ বন্ধ করুন** — শুধু "WiFi অফ, মোবাইল ডাটা অন" দেখলে হবে না,
ফোনের **WiFi আইকনটাই বন্ধ** করুন। দুইটা একসাথে চালু থাকলে ফোন WiFi-ই ব্যবহার করে,
আর টেস্টটা মিথ্যা "পাস" দেখাবে।

1. WiFi বন্ধ → মোবাইল ডাটা (4G/5G) চালু — ব্রাউজারে গুগল খুলে দেখুন নেট আছে
2. এয়ারপ্লেন মোড চালু করে আবার বন্ধ করলে নেটওয়ার্ক রিফ্রেশ হয় (ঐচ্ছিক)
3. VLC → Stream → **একই লিংক** (ঘরের `192.168.0.108` — এটা এখনো)
4. ১৫–২০ সেকেন্ড অপেক্ষা করুন

| ফল | মানে |
|---|---|
| ❌ **ছবি আসে না** (স্বাভাবিক) | `192.168.x.x` ইন্টারনেট থেকে দেখা যায় না — এটা **প্রত্যাশিত** |
| ✅ ছবি আসে | আশ্চর্য — আপনার ISP হয়তো সরাসরি পাবলিক রুট দিচ্ছে |

> **এই টেস্টটা ফেল করবেই** — কারণ `192.168.x.x` হলো ঘরের ভেতরের ঠিকানা।
> ফেল করাটা খারাপ খবর নয়। আসল প্রশ্ন পরের ধাপে।

### ১.৫ আসল প্রশ্ন — আপনার ISP কি public IP দিয়েছে?

এটাই একমাত্র নির্ণায়ক টেস্ট। ৩ ভাবে করা যায়:

**উপায় ক — রাউটারের WAN IP (সবচেয়ে সহজ)**
1. রাউটার অ্যাডমিন → **Status / WAN** পেজ → WAN IP দেখুন
2. ব্রাউজারে <https://ipinfo.io> → ইন্টারনেটের দিকের IP দেখুন
3. তুলনা করুন

| রাউটারের WAN IP | মানে | পথ |
|---|---|---|
| **`192.168.x.x` / `10.x.x.x` / `172.16–31.x.x`** | 🚫 **private IP** — রাউটার নিজেই NAT করছে, ISP-র কাছে যাওয়ার পথেই বেসরকারি ঠিকানা | **পথ খ** (পথ ক'তে কিছু নেই) |
| **`100.64.x.x` – `100.127.x.x`** | 🚫 **CGNAT** — ISP-র নিজের বেসরকারি নেটওয়ার্ক (এই রেঞ্জটা ঠিক এ কাজের জন্যই সংরক্ষিত) | **পথ খ** |
| **অন্য যেকোনো** (`103.x`, `45.x`, `1.x`…) | ✅ public IP | **পথ ক** |

> **"private IP বলছে" মানে কী?**
> - **WAN পেজে `192.168.x.x`** → আপনার রাউটার হয় দ্বিতীয় রাউটারের পিছনে (ডাবল NAT), নয়তো
>   ISP-র দেওয়া ONT/মডেম রাউটার মোডে চলছে। এখানে **আপনার রাউটারে port forward করলে
>   কোনো লাভ নেই** — আগে ওই উপরের ডিভাইসে করতে হবে।
> - **`ipinfo.io` যা দেখাচ্ছে সেটাও private** → এটা সাধারণত ব্রাউজার/নেটওয়ার্কের ক্যাশ, নয়তো
>   আপনি VPN-এ আছেন। একবার মোবাইল ডাটা দিয়ে দেখুন।
>
> দুটোর যেটাই হোক, ফল একই: **বাইরে থেকে ঢোকার পথ নেই** → পথ খ।

**private IP হলে করণীয় (দুটো আলাদা সমস্যা, দুটো আলাদা সমাধান):**

| অবস্থা | সমাধান |
|---|---|
| **ডাবল NAT** (আপনার রাউটার ISP-র ONT-এর পিছনে) | ISP-র ONT-তে **bridge mode** চালু করুন বা ISP-কে বলুন — তারপর আপনার রাউটার নিজেই public IP পাবে |
| **আসল CGNAT** (ONT/WAN-ও `100.64.x.x`) | শুধু ISP পারবে — real public IP-র আবেদন, নয়তো পথ খ |

> 📞 ISP-কে ঠিক এভাবে বলুন: *"আমার WAN IP 192.168/100.64 সিরিজে আছে, মানে আমি NAT-এর
> পিছনে। CCTV বাইরে থেকে দেখতে চাই — real public IPv4 দরকার, ফ্রি হয় কি?"*

**উপায় খ — traceroute (মোবাইল থেকেও হয়)**
Android-এ **Termux** বা যেকোনো "Traceroute" অ্যাপ → `8.8.8.8`
- প্রথম ২–৩ হপে `100.64.x.x` / `10.x.x.x` / `172.16–31.x.x` দেখলে → **CGNAT**
- প্রথম হপই পাবলিক IP হলে → public IP আছে

**উপায় গ — ISP-কে জিজ্ঞেস**
কল/মেসেজ: *"আমার কানেকশনে কি real public IPv4 আছে? CCTV বাইরে থেকে দেখতে চাই।"*
এটাই সবচেয়ে নিশ্চিত উত্তর — কারণ কখনো রাউটার IP দেখে বোঝা যায় না।

### ১.৬ ফলাফল অনুযায়ী

| ফল | পথ | ক্যামেরা | VPS |
|---|---|---|---|
| ✅ public IP আছে | **পথ ক** → ধাপ ৩ | Imou নিন | ✅ নিন |
| 🚫 **private IP / CGNAT** | **পথ খ** → ধাপ ৪ | Imou নিন | ❌ **নেবেন না** |

**আপনার ক্ষেত্রে (private IP):** VPS এখন কিনলে সেটা ক্যামেরা পর্যন্ত পৌঁছাবে না —
অর্থহীন খরচ। তাই **পথ খ**: Imou ক্যামেরা + Imou ক্লাউড, আজই লাইভ।

### ১.৭ যা এখনো করা যাবে না

- ❌ বাইরে থেকে ক্যামেরা দেখা — public IP না থাকলে অসম্ভব, এটা ডিজাইনের সীমা
- ❌ Imou ক্যামেরা ছাড়া ওয়েবঅ্যাপে লাইভ — Dahua XVR এই পথে কাজ করে না (Error1000)

> ⚠️ **পরের ধাপে যাওয়ার আগে** ধাপ ১.৫-এর উত্তরটা নিশ্চিত করুন।
> ভুল উত্তর = হয় অপ্রয়োজনীয় VPS খরচ, নয়তো ক্যামেরা কিনে দেখেন কিছু কাজ করছে না।

### ২.১ ক্যামেরা কিনুন
**Imou Bullet 2E (`IPC-F42F`)** — ৳২,৯২০–৩,৬৯০, IP67 (বাইরে/শেডে চলবে)
আরও অপশন: Ranger 2 ৳১,৯৮৫–২,৫৫০ (ঘরের ভেতর) · Cue2C ৳২,৫০০

### ২.২ Imou Life অ্যাপে যোগ করুন (শুধু ফোন)
1. অ্যাপ ইনস্টল → ক্যামেরা যোগ → WiFi (২.৪ GHz) → ডিভাইস পাসওয়ার্ড দিন
2. **Safety Code** লিখে রাখুন — এটাই RTSP-এর পাসওয়ার্ড
3. **RTSP চালু করুন:** ডিভাইস → সেটিংস → অ্যাডভান্সড → **RTSP/ONVIF** → চালু
4. অ্যাপে লাইভ খুলে দেখুন — ছবি আসছে তো?

### ২.৩ ক্যামেরার IP বের করুন
Imou Life → ডিভাইস → সেটিংস → ডিভাইস ইনফো → **IP Address** (যেমন `192.168.0.108`)
> WiFi রাউটারের DHCP-তে ক্যামেরাটাকে **fixed IP** বেঁধে দিন, নাহলে IP বদলে গেলে আবার কনফিগ করতে হবে।

## ৩. 🟢 পথ ক — public IP আছে (ক্যামেরা + VPS, মাসিক ৳০–১,২০০)

**এই পথেই সবচেয়ে ভালো:** ২৪/৭ প্রিমিয়াম সম্ভব, কতজন দেখল তাতে খরচ বাড়ে না।

### ধাপ ১ — রাউটারে পোর্ট খুলুন
- রাউটারের অ্যাডমিন প্যানেল → Port Forwarding
- `External 554 → Internal 192.168.0.108:554` (TCP)
- টেস্ট: **মোবাইল ডাটা** দিয়ে VLC-তে `rtsp://admin:<safetycode>@<public-IP>:554/cam/realmonitor?channel=1&subtype=1`
- 554 ব্লক থাকলে বাইরের পোর্ট `1554` দিয়ে ম্যাপ করুন, URL-এ `:1554` দিন

> হোস্টনেম ব্যবহার করলে DDNS (No-IP/DuckDNS) সেট করুন — public IP সাধারণত বদলায়।

### ধাপ ২ — VPS নিন
- **Oracle Cloud Always Free** আগে চেষ্টা করুন (৳০, ১০ TB/মাস)
- না পেলে Hetzner/Contabo/DigitalOcean ~$৫ (৳৭০০–১,২০০)

### ধাপ ৩ — VPS-এ স্ট্যাক চালু
```bash
ssh root@<VPS-IP>
apt update && apt install -y docker.io docker-compose-plugin git
git clone https://github.com/farukhossain25/AGRO.git && cd AGRO
```

`.env` ফাইল (repo রুটে):
```bash
STREAM_PUBLIC_HOST=stream.yourdomain.com
STREAM_EDGE_SECRET=ইচ্ছামতো_১৬_অক্ষর
ACME_EMAIL=you@yourdomain.com
```

`mediamtx.yml`-এর `paths:` নিচে ক্যামেরা যোগ করুন:
```yaml
  farm-savar-01:
    source: rtsp://admin:<SAFETY-CODE>@<PUBLIC-IP>:1554/cam/realmonitor?channel=1&subtype=1
    sourceOnDemand: true
```

চালু:
```bash
docker compose -f docker-compose.stream-vps.yml --profile public up -d
docker ps                      # ba-mediamtx আর ba-caddy চালু?
docker logs ba-caddy --tail 20 # সার্টিফিকেট এসেছে?
```

## ৪. 🔵 পথ খ — CGNAT (শুধু ক্যামেরা, VPS লাগবে না)

**VPS কিনবেন না।** এখানে VPS ক্যামেরা পর্যন্ত পৌঁছাতেই পারে না।
খরচ: ভিডিওর জন্য Imou-কে ~৳৭/দর্শক-ঘণ্টা।

### ধাপ ১ — Imou ডেভেলপার অ্যাকাউন্ট (ফ্রি)
1. <https://open.imoulife.com> → Register — **Imou Life অ্যাপের একই লগইন** দিয়ে
2. Console → **My App** → App Information → Edit → Save
3. **AppId** আর **AppSecret** কপি করুন

### ধাপ ২ — ডাটাবেস (একবার)
Supabase → SQL Editor → `supabase/sql/24_camera_cloud_bridge.sql` চালান
(এটা `cameras`-এ `cloud_provider`, `cloud_serial`, `cloud_channel` যোগ করে)

|---|---|

| `IMOU_APP_SECRET` | AppSecret |
| `IMOU_API_HOST` | `https://openapi-sg.easy4ip.com` |

### ধাপ ৪ — সাইটে ক্যামেরা যোগ

| ফিল্ড | মান |
