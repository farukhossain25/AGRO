> আবার SN `BE08ED2PAJA2C21` + admin পাসওয়ার্ড দিয়ে যোগ করে নিন, নইলে রিমোট ভিউ বন্ধ থাকবে।

# Dahua XVR → Imou ক্লাউড → ওয়েবঅ্যাপ লাইভ (মনিটর/ল্যাপটপ ছাড়া)

> ⚠️ এই অংশটা ঐতিহাসিক — উপরের সিদ্ধান্ত অনুযায়ী পুরো পথটা বেশি দূর যায়নি, তবে Open
> Platform + অ্যাডমিন সেটআপের ধাপগুলো Imou ক্যামেরার ক্ষেত্রেও হুবহু প্রযোজ্য।

**লক্ষ্য:** DH-XVR1B16-I-SSI (SN `BE08ED2PAJA2C21`) — যেটা এখন শুধু DMSS অ্যাপে দেখা যায় —
সেটার চ্যানেলগুলো ওয়েবসাইটে লাইভ দেখানো। ভিপিএস নেই, ল্যাপটপ নেই, ফার্মে কিছু চালু রাখতে হবে না।

**মূল কৌশল:** Dahua ও Imou একই ক্লাউড (Easy4IP / Lechange)। ক্যামেরাটা একটাই P2P অ্যাকাউন্টে
বাঁধা থাকতে পারে; সেটা **DMSS অ্যাকাউন্ট → Imou অ্যাকাউন্ট** করলেই আমরা Imou Open Platform API
দিয়ে HLS স্ট্রিম নিতে পারব — ঠিক যেভাবে Imou ক্যামেরার ক্ষেত্রে হয়।

## ০. বর্তমান অবস্থা (২৫ নভেম্বর ২০২৬)

| বিষয় | অবস্থা |
|---|---|
| DMSS-এ XVR অনলাইন | ✅ কাজ করছে (P2P, দূর থেকে দেখা যাচ্ছে) |
| Imou Life-এ QR স্ক্যান | ⚠️ "device already connected to another app" |
| DMSS-এ Remote Configuration | ✅ আছে (ফোন থেকেই সব সেটিংস বদলানো যায়) |
| Encoding Mode | ❌ **H.265** — ব্রাউজারে চলবে না, **H.264 করতে হবে** |
| Main Stream | 960×1080 @ 15 fps, 512 kbps |
| Sub Stream | CIF 352×288 @ 7 fps, 160 kbps → **অচল**, তাই মেইন স্ট্রিম লাগবে |

> ⚠️ "already connected" মানে **খারাপ খবর নয়** — Imou ডিভাইসটা চিনেছে। শুধু অন্য অ্যাকাউন্ট
> (আপনার DMSS অ্যাকাউন্ট) সেটা ধরে রেখেছে। Dahua-র নিয়ম: **একটা P2P ডিভাইস একসাথে একটাই
> ক্লাউড অ্যাকাউন্টে বাঁধা থাকতে পারে।**

## ১. ডিভাইসটা Imou-তে নেওয়া

### ধাপ ১ — DMSS-এ আগে যা করতে হবে
1. DMSS → `Video Stream` → প্রতিটা চ্যানেল → **Encoding Mode = H.264** → Save
   (মেইন + সাব দুটোতেই; না করলে স্ট্রিম প্লে হবে না)
2. Main Stream-এ Bitrate **1024–2048** করুন (৫১২ খুব কম, ছবি ঘোলা হবে)

> এই কাজটা **আগে** করুন, কারণ Imou-তে নেওয়ার পর DMSS থেকে ডিভাইসটা মুছে ফেলতে হবে —
> তখন আর সহজে সেটিংস বদলাতে পারবেন না।

### ধাপ ২ — P2P বাঁধন ছাড়ানো
DMSS-এ **মুছে ফেলা আর ক্লাউড থেকে বাঁধন খোলা এক জিনিস নয়**। ক্রম অনুযায়ী করুন:

1. **DMSS-এ ডিভাইস ডিলিট করুন** — Home → ডিভাইসের পাশে `···` → **Device Details** →
   নিচে **Delete** → নিশ্চিত করুন
2. **DMSS থেকে লগ আউট করুন** (অ্যাকাউন্ট মেনু → Logout)
3. **Imou Life → `+` → Scan QR / Enter SN** → `BE08ED2PAJA2C21`

#### Imou যখন "Device Password" চায়

| | |
|---|---|
| ✅ **দিতে হবে** | **XVR-এর admin পাসওয়ার্ড** — অর্থাৎ DMSS-এ DVR যোগ করার সময় যে পাসওয়ার্ড দিয়েছিলেন |
| ❌ **দিতে হবে না** | রাউটার/WiFi পাসওয়ার্ড, Imou অ্যাকাউন্টের পাসওয়ার্ড, ইমেইল পাসওয়ার্ড |

Imou ইউজারনেম চায় না, কারণ ও ধরে নেয় ইউজারনেম `admin` (Dahua রেকর্ডারের ডিফল্ট)।

> ⚠️ **এই ধাপটাই "point of no return"** — পাসওয়ার্ড দিয়ে বাইন্ড সফল হলে DMSS-এ ডিভাইস আর
> থাকবে না। তাই **আগে** Encoding = H.264 আর bitrate ১০২৪+ করে নিন।
>
> ⚠️ **ভুল পাসওয়ার্ড বারবার দেবেন না** — Dahua ৫ বার ভুলে কিছুক্ষণের জন্য লক করে
> (৫–৩০ মিনিট), বারবার করলে সময় বাড়ে।

**পাসওয়ার্ড মনে না থাকলে:** DMSS → `Device Details` → `Device Configuration` →
Modify Device Password (পুরোনোটা লাগবে) → না হলে Dahua-র Forgot Password ফ্লো →
সর্বশেষ উপায় XVR-এর রিসেট বাটন (সব সেটিংস মুছে যাবে, তাই শেষে)।

### ধাপ ৩ — ফলাফল অনুযায়ী
| যা দেখবেন | মানে | পরের কাজ |
|---|---|---|
| চ্যানেল লিস্ট আসে ✅ | বাঁধন ছাড়া হয়েছে | পরের ধাপে যান |
| এখনও "already bound" + আংশিক ইমেইল | অ্যাকাউন্টটা এখনও ধরে আছে | নিচে ১ক |
| "device not supported" | Dahua রেকর্ডার Imou-তে সাপোর্টেড নয় | নিচে ১খ |

**১ক — অ্যাকাউন্ট-ধারক ইমেইলটা আপনার হলে** (সম্ভবত তাই, কারণ DMSS আর Imou
অ্যাকাউন্ট আলাদা হলেও দুটোই Dahua-র): কোনো unbind আপিলের দরকার নেই —
আপনার নিজের DMSS অ্যাকাউন্টে ঢুকে ডিভাইস ডিলিট + লগ আউট করাই যথেষ্ট।
না হলে Imou Life-এ **Apply to Unlink** → SN লেবেলের ছবি দিয়ে আবেদন (২৪ ঘণ্টা)।

**১খ — সাপোর্টেড না হলে:** Imou পথ বন্ধ। তখন **RTMP পুশ** (`Network → Port → RTMP`);
অথবা সেলারদের জন্য একটাই Imou ক্যামেরা (৳২,৫০০–৫,০০০) — সবচেয়ে কম ঝামেলা।

> 🔁 **ফিরে যাওয়া দরকার হলে:** Imou থেকে ডিভাইস ডিলিট করলেই আবার DMSS-এ যোগ করা যাবে।
> পুরো প্রক্রিয়াটা উল্টো দিকেও কাজ করে, তাই পরীক্ষা করতে ভয় নেই।

## ২. Imou Open Platform (আমাদের কোডের জন্য)

1. `open.imoulife.com` → ডেভেলপার অ্যাকাউন্ট (ফ্রি) → Console → **My App**
2. **AppId** আর **AppSecret** কপি করুন
3. **গুরুত্বপূর্ণ:** অ্যাপের সাথে ডিভাইসটা বাইন্ড করতে হবে — Console → Device Management →
   `BE08ED2PAJA2C21` যোগ করুন। না করলে API-তে ডিভাইস লিস্ট **খালি** আসবে
   (এটা খুব সাধারণ ভুল, আর অনেকক্ষণ খোঁজাখুঁজি করাতে হয়)
4. Vercel-এ env:

```
IMOU_APP_ID=<AppId>
IMOU_APP_SECRET=<AppSecret>
IMOU_API_HOST=https://openapi-sg.easy4ip.com   # বাংলাদেশ = সিঙ্গাপুর ডেটা সেন্টার
IMOU_STREAM_ID=0                                # 0 = HD মেইন (XVR-এর সাব-স্ট্রিম অচল)
```

> ভুল রিজিওন দিলে লগইন সফল হবে কিন্তু ডিভাইস লিস্ট খালি আসবে। বাংলাদেশ/দক্ষিণ এশিয়া =
> `openapi-sg.easy4ip.com`।

## ৪. যাচাই

```
GET /api/cam/token            → 402 (সাবস্ক্রিপশন নেই) / 404 / 409 / 200
GET /api/cam/live/<id>/index.m3u8?t=<JWT>   → 200 + m3u8 টেক্সট
```

প্লেতে সেগমেন্টগুলো `/api/cam/live/<id>/seg/...` দিয়ে যাবে (HMAC সাইন করা)।
ব্রাউজারে সরাসরি vendor URL আসবে না — সেটাই ডিজাইন।

সমস্যা হলে চেক করুন:
- `402` → ওই ইউজারের প্রিমিয়াম/সাবস্ক্রিপশন নেই
- `502` → Imou থেকে HLS পাওয়া যায়নি (ডিভাইস অফলাইন, বা H.265)
- `404` → ডিভাইস/চ্যানেল ভুল (চ্যানেল ০-ভিত্তিক কি না দেখুন)

## ৫. সীমাবদ্ধতাগুলো সত্যি করে বলে রাখা

- **রেজোলিউশন:** XVR-এর মেইন স্ট্রিম ৯৬০×১০৮০ @ ১৫ fps — সেলারদের সাইটে দেখানোর জন্য
  যথেষ্ট, কিন্তু Imou ক্যামেরার মতো ঝকঝকে নয় (OEM ইমেজ সেন্সর + কম বিটরেট)।
- **আপলিংক:** খামারের ইন্টারনেট আপলোড দুর্বল হলে একাধিক ভিজিটর একসাথে দেখলে lag হবে।
  Imou ক্লাউড এক্ষেত্রে নিজে ট্রান্সকোড করে না, তাই ব্যান্ডউইথটাই সীমা।
- **এক ডিভাইস = এক অ্যাকাউন্ট:** DMSS আর Imou-তে একসাথে থাকবে না। ঘরে দেখার জন্য
  Imou Life-ই ব্যবহার করতে হবে (ছবি/রেকর্ডিং সবই থাকবে, শুধু পেশাদার কিছু সেটিংস কমবে)।
- **ভবিষ্যতে:** সেলারদের জন্য Imou ক্যামেরা নিলে একই পাইপলাইনে যোগ হবে, শুধু ছবি অনেক ভালো।
  XVR-টা থাকবে না — তাই এখনকার সেটআপটা পরীক্ষামূলক ধরে নিন।

## ৬. বিকল্প (যদি Imou পথে বাধা আসে)

1. **RTMP পুশ:** XVR-এ `Network → Port → RTMP` থাকলে XVR নিজেই একটা সার্ভারে পুশ করতে পারে।
   হোস্টিং: AWS t3.micro ~$২/সপ্তাহ (দেখুন `docs/live-camera-aws-test.md`)
2. **আলাদা Imou ক্যামেরা:** সবচেয়ে নির্ভরযোগ্য, সেরা ছবি, কোনো VPS নেই
3. **DMSS device sharing:** শুধু অন্য DMSS ইউজার দেখতে পাবে — ওয়েবঅ্যাপে আসবে না, তাই এটা ওয়েবের জন্য অচল
